# In Dev

---------------
В данном разделе будут рассмотрены ключевые нейросетевые архитектуры для классификации изображений.  
  
Архитектуры для рассмотрения:  
* LeNet
* AlexNet
* ResNet
* EfficientNet
* ViT

Используемые датасеты:
* MNIST - для архитектуры LeNet
* ImageNet10 - для AlexNet, ResNet, EfficientNet, ViT
